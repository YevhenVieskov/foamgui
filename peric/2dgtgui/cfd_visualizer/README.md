# CFD Visualizer - Star CCM+ Style

A Star CCM+ like CFD visualization tool built with Python, PyVista, and PyQt.

## Features

- **3D Visualization**: Vector fields, pressure/velocity contours, plane sections
- **Residual Monitoring**: Star CCM+ style convergence plots
- **Interactive UI**: Dockable panels, simulation tree, toolbar
- **Multiple Formats**: VTK, VTP, VTU, CSV support

## Installation

```bash
pip install -r requirements.txt
