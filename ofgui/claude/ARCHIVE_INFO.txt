ARCHIVE CONTENTS
================================================================================

This archive contains the complete OpenFOAM GUI project with all enhancements.

================================================================================

2. openfoam_gui.zip     (143 KB) - Windows/universal

EXTRACTION
================================================================================

TAR.GZ (Linux/macOS):
  tar -xzf openfoam_gui.tar.gz
  cd openfoam_gui

ZIP (Windows/Universal):
  unzip openfoam_gui.zip
  cd openfoam_gui

QUICK START
================================================================================

1. Extract archive:
   tar -xzf openfoam_gui.tar.gz

2. Install:
   cd openfoam_gui
   bash install.sh

3. Run:
   openfoam-gui
   # or
   python main.py

ALTERNATIVE: DOCKER
================================================================================

1. Extract and navigate:
   tar -xzf openfoam_gui.tar.gz
   cd openfoam_gui

2. Build and run:
   docker-compose up -d

SYSTEM REQUIREMENTS
================================================================================

Operating System:     Linux, macOS, Windows (WSL2)
Python:              3.8 or higher
OpenFOAM:            2506 or compatible
RAM:                 4GB minimum, 8GB recommended
Disk Space:          2GB (with dependencies)
GPU:                 OpenGL 3.0+ capable

DEPENDENCIES
================================================================================

Core:
  - PyQt6 >= 6.5.0
  - pyvista >= 0.42.0
  - vtk >= 9.2.0
  - numpy >= 1.24.0
  - matplotlib >= 3.7.0

Optional (Development):
  - pytest >= 7.4.0
  - pytest-qt >= 4.2.0
  - black >= 23.0.0
  - flake8 >= 6.0.0
